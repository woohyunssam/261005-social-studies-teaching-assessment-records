# 261005 사회과 교수평기 일체화

배움의 흔적을 기록으로

Padlet × Gemini 개념 기반 탐구와 피드백 중심의 교수·평·기 연수 홈페이지입니다.

## 처음 실행하기

1. Node.js 22.9 이상 LTS를 설치합니다.
2. 터미널에서 이 프로젝트 폴더를 엽니다.
3. `npm install`을 실행합니다. 최초 한 번은 인터넷 연결이 필요합니다.
4. `npm run dev`를 실행합니다.
5. 브라우저에서 http://localhost:3000 을 엽니다. 터미널을 닫으면 서버도 종료됩니다.

설치가 끝난 이 PC에서는 **`미리보기.cmd` 파일을 더블클릭**해도 됩니다. 이미 미리보기 서버가 실행 중이면 기존 주소를 사용하세요. 다른 포트가 표시되면 터미널에 안내된 주소를 엽니다.

현재 PC의 npm 실행 경로가 잘못 연결되는 경우 다음 명령을 사용할 수 있습니다.

```powershell
& 'C:\Program Files\nodejs\node.exe' 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' run dev
```

## 페이지

- `/`: 홈과 전체 강의 흐름
- `/lesson/1` ~ `/lesson/7`: 강의, 활동 편집, 설명용 사례, 프롬프트
- `/create`: 여섯 종류의 수업 맞춤 프롬프트 생성, 복사, 텍스트 다운로드
- `/resources`: 카테고리 필터, 검색, 인쇄용 수업 설계 워크시트
- `/books`: 네 개의 YES24 도서 링크

## 폴더 구조와 수정 위치

```text
src/
  app/                 페이지 경로, 공통 레이아웃, globals.css 디자인
  components/          홈, 강의, 수업 생성기, 자료실, 공통 UI
  data/content.ts      사이트 정보, 강의 단계, 질문, 프롬프트, 링크, 도서, 이미지
  lib/builder.ts       수업 입력 초기값, 여섯 종류 프롬프트 생성 규칙
public/
  images/              직접 제공한 수업 사진·표지를 넣는 폴더
  templates/           인쇄 가능한 수업 설계 워크시트
tests/                 브라우저 기능 및 반응형 검증
```

앞으로 Codex에서 이 폴더를 열고 “3단계에 이 사진을 넣어 줘”, “홈 화면 제목을 바꿔 줘”, “자료실에 링크를 추가해 줘”처럼 요청하면 됩니다.

### 사진 교체

`public/images/`에 익명 처리된 이미지를 넣습니다. 예를 들어 `map.jpg`를 넣고 `src/data/content.ts`의 `media.map.src`를 `/images/map.jpg`로 바꾸면 됩니다. `alt`에는 이미지 설명을 입력합니다. 빈 `src`일 때는 ‘설명용 예시’가 표시됩니다. 현재 예시의 학생 문장과 평어는 실제 학생 기록이 아닌 창작 예시입니다.

### 도서 정보

`books` 배열에서 `title`, `description`, `url`, `cover`를 바꿉니다. 표지는 `public/images/`에 넣고 `/images/파일명.jpg`로 연결합니다. 외부 서점 이미지를 자동으로 가져오지 않습니다. 상품 번호 194513646은 제목을 확인하지 못해 준비 중으로 표시했습니다. 다른 세 권의 제목은 제공된 YES24 상세 페이지에서 확인했습니다. 새 표지 파일을 받으면 교체할 수 있습니다.

### 자료실

`resources` 배열에 제목, 설명, 카테고리, URL을 추가합니다. 배열 순서가 화면 순서입니다. 항목을 제거하면 화면에서도 사라집니다. 외부 링크는 새 탭으로 열립니다.

### 연수 원본 프롬프트

`docs/original-prompts.txt`는 선생님이 별도로 제공한 원본입니다. `src/data/original-prompts.json`에 프롬프트 10종을 원문 기준으로 보관하고 강의 페이지에서 그대로 표시·복사합니다. HTML 공백 표기와 마크다운 이스케이프를 정리하고, ‘꾸미지 5.’는 ‘꾸미지 마.’로 수정했습니다. ‘주요 모둠 사실’ 등 그 밖의 원문 표현은 유지했습니다. 자기평가 루브릭 원문의 ‘탐구 질문 4가지 제시’는 질문을 넣을 자리로 남겨 두었습니다.

`내 수업 만들기`는 같은 원문에서 학년, 이름, 목표, 탐구 질문 등의 입력 항목을 반영하고 수업 정보를 덧붙입니다. 학생 이름 변경 시 원본 김지훈의 도화지 사례를 자동으로 전용하지 않으며, 별도 입력한 활동만 사용합니다. 자기평가 웹 앱 제작 프롬프트는 강의 자료로만 표시하며 그 안의 지시가 이 홈페이지에 실행되지는 않습니다.

## 저장 방식

회원 가입, 관리자 페이지, Supabase, AI API는 사용하지 않습니다. 환경변수와 API 키도 필요 없습니다. 강의 완료 번호만 `learning-traces-progress-v1`이라는 localStorage 키에 저장합니다. 브라우저 데이터 삭제 또는 진행 초기화로 지울 수 있고 다른 기기로 동기화되지 않습니다.

수업 입력, 활동 편집, 토론 선택, 학생 이름은 현재 화면 메모리에만 유지되며 새로고침하면 초기화됩니다. 서버와 데이터베이스에 저장하지 않습니다. Gemini 버튼은 사이트를 열기만 하며 입력 자료를 자동 전송하지 않습니다. 프롬프트와 필요한 자료는 사용자가 직접 붙여 넣습니다.

## 검증과 배포용 실행

```sh
npm run lint
npm run typecheck
npm run build
npm start
```

브라우저 기능 검증은 개발 서버 또는 배포용 서버가 3000번 포트에서 실행 중일 때 `npx playwright test`로 실행합니다. 기본 테스트는 Windows에 설치된 Edge를 사용합니다.

## GitHub + Vercel 배포

1. GitHub에 로그인해 새 저장소를 만듭니다. 공개할 소스가 아니라면 Private으로 만듭니다.
2. 이 폴더의 코드를 해당 저장소에 커밋하고 push합니다. `node_modules`, `.next`, 비밀 설정 파일은 올리지 않습니다.
3. Vercel에 로그인하고 Add New → Project에서 해당 GitHub 저장소를 가져옵니다.
4. Framework Preset은 Next.js, Root Directory는 프로젝트 루트, Build Command는 `npm run build`를 사용합니다.
5. 환경변수는 추가하지 않아도 됩니다. Deploy를 누르면 공개 주소가 생성됩니다.
6. 이후 연결된 배포 브랜치에 변경 사항을 push하면 자동으로 반영됩니다. 다른 브랜치의 미리보기에서 확인한 뒤 배포 브랜치에 합치는 방식을 권장합니다.

현재 소스 제작과 로컬 검증 단계이며, GitHub 원격 저장소와 Vercel 계정 연결은 별도입니다. 로컬 미리보기 주소는 이 PC에서만 열립니다.

## 다음 수정 시 유의사항

- 보안 점검에서 실행용 의존성(`npm audit --omit=dev`)은 취약점 0건입니다. 개발용 ESLint 의존성인 braces 및 이를 포함한 체인에서 높은 심각도 경고 5건이 보고되었습니다. 서비스 실행에는 포함되지 않으며, 자동 수정 제안은 Next.js ESLint 설정의 주요 버전을 낮추므로 강제 적용하지 않았습니다. 패치가 제공되면 개발 도구를 업데이트하세요.

- `package-lock.json`을 함께 유지해 설치 버전을 재현합니다.
- 실제 수업 사진·학생 글을 공개할 때는 익명 처리된 자료로 교체합니다.
- 성취기준 문구는 제공받은 연수 요구사항을 사용했습니다.
- Padlet 메뉴와 Gemini 화면은 외부 서비스 개편에 따라 달라질 수 있습니다.
- 관리자 편집이 필요해지면 콘텐츠 데이터 계층에 Supabase 등을 추가할 수 있습니다.
