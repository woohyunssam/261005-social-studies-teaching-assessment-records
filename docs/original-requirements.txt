당신은 교육용 웹 서비스와 교원 연수용 홈페이지를 전문적으로 개발하는 시니어 풀스택 개발자이자 UX 디자이너다.

다음 요구사항을 만족하는 실제 배포 가능한 웹사이트를 개발해라.

프로젝트명:
배움의 흔적을 기록으로
Padlet × Gemini 개념 기반 탐구와 피드백 중심의 교수·평·기 일체화

==================================================
1. 프로젝트 목적
==================================================

이 사이트는 초등학교 교사를 대상으로 한 교원 연수용 웹사이트이다.

단순한 강의자료 모음이 아니라 강의를 들으며 순서대로 실습하고, 강의가 끝난 후에도 교사가 자신의 수업을 설계할 때 다시 방문해 활용할 수 있는 "교수·평·기 실습 플랫폼"이어야 한다.

핵심 메시지:

"학생이 수업에서 남긴 모든 흔적은 평가 자료가 될 수 있습니다."

"그 흔적을 성취기준과 탐구 질문으로 다시 읽으면 기록이 됩니다."

"수업 공간 = 평가 공간 = 기록 데이터"

전체 흐름:

교육과정
→ 탐구 질문
→ 학생 활동
→ 피드백
→ 자기평가
→ 과정중심평가
→ 학생별 데이터 추출
→ NEIS 평어

- Pretendard 우선

- 접근성 고려
- 초등교사 연수에 어울리는 친근하고 전문적인 분위기

좌우 2단 레이아웃 적극 활용

모바일:
1단 세로 레이아웃

강의 중 프로젝터로 보여줄 수 있으므로 글자는 충분히 크게 만든다.

9. 실제 수업의 4개 탐구 질문
==================================================

카드 4개로 보여준다.

1. 사실적 질문
우리 주변에는 어떤 장소들이 있으며,
우리는 그곳에서 주로 무엇을 하는가?

2. 개념적 질문
같은 장소라도 사람마다 느끼는 감정이나 생각,
즉 장소감이 다른 까닭은 무엇일까?

3. 논쟁적 질문
만약 우리 동네에서 경찰서나 소방서와 같이
안전을 지켜주는 장소가 사라진다면 어떤 일이 발생할까?

4. 실천적 질문
우리가 사는 곳을 더 살기 좋은 곳으로 만들기 위해
내가 할 수 있는 것은 무엇일까?

18. 학생 자기평가
==================================================

학생 이름 입력

4개 카드:

1.

우리 동네 알기
🏷️ 우리 동네 장소 탐험가

🌟 완벽해요
장소와 그곳에서 하는 일을 아주 자세히 설명할 수 있음

👍 잘했어요
여러 장소와 그곳에서 하는 일을 알고 있음

🌱 노력할래요
어떤 장소가 있는지 더 살펴봐야 함

이유 입력

2.

다양한 마음 이해하기
💗 마음 읽기 척척 박사

🌟
사람마다 장소감이 다른 이유를 확실히 설명할 수 있음

👍
장소에 대한 생각과 기분이 다를 수 있음을 이해함

🌱
생각이 왜 다른지 더 고민할 필요가 있음

이유 입력

3.

안전의 소중함 알기
🛡️ 우리 동네 든든 보안관

🌟
안전 관련 기관이 사라졌을 때 생길 구체적인 어려움을 설명함

👍
우리 동네 안전을 지켜주는 곳의 중요성을 이해함

🌱
안전을 지켜주는 장소의 역할을 더 알아볼 필요가 있음

이유 입력

4.

더 좋은 동네 만들기
🏠 살기 좋은 마을 메이커

🌟
동네를 위해 자신이 할 수 있는 일을 찾아 실제 실천함

👍
문제 해결 아이디어를 내고 실천하려 노력함

🌱
자신이 할 수 있는 일을 앞으로 더 찾아볼 필요가 있음

이유 입력

이 페이지는 실제 학생용 평가 앱을 새로 만드는 것이 아니라
강의 사례로 설명하는 페이지이다.

6. 성장 기록

중요 문구:

"등급부터 매기지 말고 학생이 실제로 남긴 근거부터 찾습니다."

==================================================
21. 과정중심평가 Gemini 프롬프트
==================================================

다음 프롬프트를 콘텐츠로 등록.

나는 초등학교 3학년 교사야.

학생들이 한 달 동안 패들렛에 남긴 활동 기록
(감정 지도, 토론 글, 답사 기록, 댓글 등)을 바탕으로
과정 중심 평가를 하려고 해.

아래의 최종 목표와 4가지 탐구 질문을 기준으로,
교사가 학생의 성취 수준을 평가할 수 있는
3단계(우수, 보통, 노력 요함) 평가 루브릭을 표 형태로 만들어 줘.

단순한 지식 암기 여부가 아니라,
학생의 사고가 확장되는 과정과
타인과 소통하는 태도가 드러나게 작성해 줘.

최종 목표:

사람들은 각자의 경험에 따라 장소에 대해 서로 다른 느낌을 가지며,
우리가 사는 곳을 더 살기 좋은 곳으로 만들기 위해
문제를 찾아 개선을 실천한다.

탐구 질문 4개를 함께 삽입.

22. PDF 기반 학생 평가 프롬프트
==================================================

프롬프트:

첨부한 PDF 파일은
우리 반 학생들이 한 달 동안 패들렛에 작성한
모든 활동 기록이다.

앞에서 만든 과정 중심 평가 루브릭을 기준으로
학생 개개인의 활동을 분석해 줘.

학생별로 4가지 탐구 질문에 대해
우수 / 보통 / 노력 요함
수준을 표로 정리해 줘.

중요:

학생이 실제 PDF에 작성했던
구체적인 문장이나 반응을 찾아
평가의 근거로 함께 제시해 줘.
